# the-Hiro-engine.com

Static GitHub Pages site for The Hiro Engine.

## Homepage video

The homepage plays `/assets/hiro-homepage.mp4` as the primary hero content.

The video autoplays muted with inline playback enabled and retains player controls so visitors can unmute the soundtrack. `ComingSoonHiro.png` is retained as the poster image while the video loads or if autoplay is unavailable.
